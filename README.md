# 🧠 Machine Learning Projects: Consumer Behavior & Sleep Health Analysis

This repository contains multiple Machine Learning projects focused on real-world behavioral data analysis and predictive modeling using classification and regression techniques.

---

# 📁 Projects Included

## 1️⃣ Consumer Shopping Trends Analysis

### 🎯 Objective
To analyze customer shopping behavior and predict **shopping preference (Online / Store / Hybrid)** using machine learning techniques.

---

### 📊 Dataset Features
- Age, Gender, Monthly Income
- Daily internet & social media usage
- Online orders & store visits
- Average online & store spending
- Impulse buying score
- Brand loyalty score
- Environmental awareness
- Product preference behavior

---

### 🤖 ML Models Used
- Logistic Regression
- Random Forest Classifier
- XGBoost Classifier

---

### 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

---

### 🎯 Target Variable
- `shopping_preference`

---

## 2️⃣ Sleep Health & Daily Performance Analysis

### 🎯 Objective
To predict **cognitive performance score** and analyze how sleep patterns, lifestyle, and health factors impact daily performance and well-being.

---

### 📊 Dataset Features
- Sleep duration, sleep quality
- REM and deep sleep percentage
- Stress score
- Screen time before bed
- Caffeine and alcohol intake
- Exercise and step count
- Work hours and occupation
- Mental health condition
- Heart rate and environmental factors

---

### 🤖 ML Models Used
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- Logistic Regression (for classification tasks)

---

### 📈 Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Accuracy (for classification tasks)

---

### 🎯 Target Variables
- `cognitive_performance_score` (Regression)
- `sleep_disorder_risk` (Classification)
- `felt_rested` (Binary Classification)
